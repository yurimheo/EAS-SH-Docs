EAS.SH POLICY

개인정보처리방침

시행일: 2026년 11월 22일

Google Calendar 읽기 전용 OAuth 토큰 로컬 암호화 광고·판매 목적 사용 안 함

1. 개요

EAS.SH(이하 “앱”)는 사용자의 Google Calendar 일정을 불러와 검토하고, 사용자가 최종 확정한 업무 일정만 회사 EAS(Enterprise Application System)에 등록하도록 돕는 데스크톱 애플리케이션입니다. 본 방침은 앱이 Google 사용자 데이터를 포함한 정보를 어떻게 접근·이용·저장·전송 및 삭제하는지 설명합니다.

2. 접근하는 정보

앱은 사용자의 명시적인 동의를 받은 후 다음 정보에 접근합니다.

  • Google 계정 기본 정보: 연결된 계정을 표시하기 위한 이메일 주소
  • Google Calendar 정보: 사용자가 접근할 수 있는 캘린더 목록과 캘린더 이름
  • 일정 정보: 일정 식별자, 제목, 설명, 시작·종료 일시 및 종일 일정 여부
  • 인증 정보: Google OAuth 액세스 토큰과 갱신 토큰

앱은 https://www.googleapis.com/auth/calendar.readonly 범위만 사용하며 Google Calendar 일정을 생성·변경·삭제하지 않습니다.

3. 정보 이용 목적

  • 연결된 Google 계정을 확인하고 표시
  • 사용자가 선택한 기간의 일정을 가져와 EAS 등록 후보 생성
  • 중복 일정 비교, 제외 항목 분류 및 사용자 검토 지원
  • 사용자가 최종 승인한 일정의 EAS 등록
  • EAS 서버에서 등록 결과를 다시 조회하여 표시

Google 사용자 데이터는 광고, 사용자 프로파일링 또는 판매 목적으로 이용하지 않습니다.

4. 정보 저장과 보안

Google OAuth 토큰은 사용자의 기기에 저장되며, Electron safeStorage를 통해 Windows DPAPI 또는 macOS Keychain 기반으로 암호화됩니다. 캘린더 선택, 일정 제목 접두어, 기본 근무시간, 프로젝트 매핑 등 앱 설정도 사용자의 기기에 저장됩니다.

Google Calendar에서 가져온 일정은 실행 중 검토를 위해 앱 메모리에서 처리됩니다. 앱은 원격 분석 또는 광고 서버를 운영하지 않으며, Google 비밀번호와 EAS 비밀번호를 자체 파일에 저장하지 않습니다.

5. 정보 전송 및 공유

앱은 Google API에서 일정 정보를 사용자의 기기로 가져옵니다. 사용자가 최종 등록을 승인하면 선택된 일정의 제목, 날짜, 시간 및 업무 분류 등 EAS 등록에 필요한 정보가 회사 EAS 서버로 전송됩니다. 이는 사용자가 요청한 EAS 등록 기능을 수행하기 위한 것입니다.

앱 운영자는 Google 사용자 데이터를 판매하지 않으며 광고 사업자나 데이터 브로커와 공유하지 않습니다. EAS에 등록된 정보의 보관과 처리는 해당 회사의 EAS 운영 정책을 따릅니다.

6. 보유 기간 및 삭제

OAuth 토큰은 사용자가 연결을 해제하거나 앱의 로컬 데이터를 삭제할 때까지 기기에 보관됩니다. 사용자는 앱에서 Google 계정을 변경하거나 연결을 해제할 수 있고, Google 계정의 타사 앱 액세스 관리에서 언제든 권한을 철회할 수 있습니다.

Windows에서는 사용자 AppData의 EAS.SH 폴더, macOS에서는 사용자 Application Support의 EAS.SH 폴더를 삭제하여 앱의 로컬 설정과 인증 데이터를 제거할 수 있습니다. EAS에 이미 등록된 기록은 회사 EAS의 절차에 따라 정정 또는 삭제해야 합니다.

7. Google API 데이터 정책 준수

EAS.SH가 Google API로부터 수신한 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy 및 Limited Use 요구사항을 준수합니다.

8. 이용자의 선택과 권리

사용자는 Google 연결을 하지 않거나, 연결된 계정을 변경하거나, 권한을 철회할 수 있습니다. Google Calendar 일정은 등록 전에 앱에서 검토·수정·제외할 수 있으며, 최종 승인하지 않은 일정은 EAS 등록 요청에 사용되지 않습니다.

9. 아동의 개인정보

앱은 회사 업무용으로 제공되며 만 14세 미만 아동을 대상으로 하지 않습니다.

10. 방침 변경

앱 기능이나 데이터 처리 방식이 변경되면 본 방침을 갱신하고 상단의 시행일을 변경합니다. 중요한 변경은 배포 안내 또는 앱 내 공지를 통해 알릴 수 있습니다.

11. 문의

개인정보처리방침, Google 데이터 이용 또는 삭제에 관한 문의는 EAS.SH 지원 페이지를 통해 접수할 수 있습니다.

1. Overview

EAS.SH (the “App”) is a desktop application that helps users import and review Google Calendar events and submit only the work schedules they explicitly approve to their company Enterprise Application System (“EAS”). This Policy explains how the App accesses, uses, stores, transfers, and deletes information, including Google user data.

2. Information We Access

After the user provides explicit consent, the App accesses:

  • Basic Google account information: the email address used to identify the connected account
  • Google Calendar information: calendar lists and names available to the user
  • Event information: event identifiers, titles, descriptions, start and end times, and all-day status
  • Authentication information: Google OAuth access and refresh tokens

The App uses only the https://www.googleapis.com/auth/calendar.readonly scope and does not create, modify, or delete Google Calendar events.

3. How We Use Information

  • Identify and display the connected Google account
  • Import events from a user-selected calendar and date range
  • Prepare EAS candidates and assist with duplicate checks, exclusions, and review
  • Submit schedules expressly approved by the user to EAS
  • Retrieve and display the resulting registration status from EAS

Google user data is not used for advertising, user profiling, or sale.

4. Storage and Security

Google OAuth tokens are stored on the user’s device and encrypted through Electron safeStorage, backed by Windows DPAPI or macOS Keychain. App preferences—including the selected calendar, event prefix, default working hours, and project mappings—are also stored on the user’s device.

Imported Google Calendar events are processed in application memory for review during use. The App does not operate analytics or advertising servers and does not save Google or EAS passwords in its own files.

5. Transfers and Sharing

The App retrieves event data from Google APIs directly to the user’s device. When the user approves final submission, information required for EAS registration—such as the selected event title, date, time, and work classification—is transferred to the company EAS server to perform the function requested by the user.

Google user data is not sold or shared with advertisers or data brokers. Information registered in EAS is retained and processed under the applicable company EAS policy.

6. Retention and Deletion

OAuth tokens remain on the device until the user disconnects the account or removes the App’s local data. Users can change or disconnect their Google account in the App and revoke access at any time through Google Account third-party access settings.

To remove local settings and authentication data, delete the EAS.SH folder under the user’s AppData directory on Windows or Application Support directory on macOS. Records already submitted to EAS must be corrected or deleted under the company’s EAS process.

7. Google API Data Policy

EAS.SH’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

View the Google API Services User Data Policy

8. User Choice and Control

Users may choose not to connect Google, change the connected account, or revoke access. Calendar events can be reviewed, edited, or excluded before registration. Events that the user does not finally approve are not used in an EAS submission request.

9. Children’s Privacy

The App is provided for workplace use and is not directed to children under 14.

10. Changes to This Policy

If App functionality or data practices change, this Policy will be updated and the effective date above will be revised. Material changes may also be communicated through distribution notices or in-App messaging.

11. Contact

Questions about this Policy, Google data use, or deletion requests can be submitted through the EAS.SH support page.
